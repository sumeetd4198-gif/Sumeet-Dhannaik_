# Sweet Crumbs Bakery

A responsive bakery website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive mobile/desktop layout
- Cakes, pastries, breads and cookies
- Category filtering
- Product images, descriptions and prices
- Bakery gallery
- Order inquiry form with JavaScript validation
- Contact section
- GitHub Pages ready

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository (for example `sweet-crumbs-bakery`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide your Pages URL after deployment.

The product/gallery photos are loaded from Unsplash URLs, so an internet connection is needed for those images.
